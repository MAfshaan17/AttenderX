AttenderX revolutionizes academic attendance by moving away from archaic roll-calls and proxy-prone ID scanners. By leveraging browser-based AI Face Detection and Real-time Eye Blink Verification (Liveness Detection), AttenderX ensures that the student is physically present in front of the device.

---

## ✨ Features

* **Anti-Spoofing Liveness Detection:** Employs advanced computer vision (`face-api.js`) to calculate the Eye Aspect Ratio (EAR). The system forces the user to blink, ensuring a printed photo or static image cannot be used to fake attendance.
* **Academic Subject Tracking:** A fully-fledged student portal where users can input their semester subjects, course codes, and assigned credits.
* **Smart Schedule Engine:** The Live Attendance webcam automatically detects the current day of the week and dynamically filters the class selection to only show subjects the student is scheduled for today.
* **Rich Role-Based Dashboards:**
  * **Students:** View personalized Academic Overviews. Track total attended classes, monitor credit loads, and view a visual 30-day Calendar.
  * **Admins:** View global metrics, daily scan volume, and session distributions across all departments.
* **Smart Warnings:** If a student's attendance for any subject drops below 75%, the system immediately triggers a visual "Shortage" alert in their dashboard.
* **Voice Feedback:** Native browser speech synthesis speaks to the user, guiding them to "Position your face" or warning them if "No blink was detected."

## 🏗️ Architecture Stack

### **Frontend (Client)**
* **Framework:** React + Vite
* **Styling:** Tailwind CSS + Glassmorphism UI
* **AI Engine:** `face-api.js` loaded via jsDelivr CDN
* **Charts & Analytics:** `Chart.js` & `react-chartjs-2`
* **Routing:** `react-router-dom`

### **Backend (Server)**
* **Framework:** Node.js with Express
* **Database:** MongoDB via Mongoose
* **Authentication:** JWT (JSON Web Tokens) & bcryptjs
* **CORS:** Secure cross-origin resource sharing configured

## 🚀 Getting Started

### Prerequisites
* Node.js (v18 or higher)
* MongoDB (Running locally on `mongodb://localhost:27017` or via MongoDB Atlas)

### 1. Backend Setup
```bash
cd server
npm install
# Ensure MongoDB is running, then populate demo data
node seed.js
npm run dev
```

### 2. Frontend Setup
```bash
cd client
npm install
npm run dev
```

### 3. Usage & Testing
1. Navigate to `http://localhost:5173`
2. **Login:** Use the demo student account generated by the seeder (Roll No: `003`, Password: `password123`)
3. **Configure:** Go to **My Subjects** and add a subject for the current day of the week.
4. **Attend:** Go to **Live Attendance**, select the subject, and test the Blink Detection!
5. **Dashboard:** View your real-time updated Attendance Calendar and analytics.

## 🔒 Security Measures

* **JWT Bearer Auth:** All API routes are protected by robust JWT middleware.
* **Password Hashing:** Passwords are never stored in plain text, secured by bcrypt.
* **CORS Protection:** Configured to only accept requests from trusted frontend origins.
* **Liveness Checks:** Deep-learning facial landmark detection prevents photo-spoofing entirely on the client-side.
